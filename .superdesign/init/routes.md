# Routes

- `/` — `app/page.tsx` — client dashboard shell, wallet connect control and `Vault`.
- `/api/keeper/heartbeat` — POST authenticated keeper heartbeat.
- `/api/treasuries/[vault]/activity` — GET indexed activity.
- `/api/treasuries/[vault]/alerts` — GET unresolved persisted alerts.
- `/api/treasuries/[vault]/keeper` — GET keeper status.
- `/icon.svg` — app icon.
